# 1.2.1

## Time tab, full web parity

The macOS Time tab now matches the web TimeTracker behavior:

- Log Uber, transport, and miscellaneous expenses via ExpenseEntrySheet
- Mark a month as paid with confirmation; row-level lock indicators
- Inline expense rows in day groups
- Payment history block + month picker dropdown
- Expanded stats grid: Odpracováno / Jízdy / Za práci / Celkem k vyplacení
- Paid-month lock prevents accidental edits

## Tracker fixes

- Status pill on tracker rows now actually shows percentage (was invisible against tinted backgrounds)
- Planning task list pill displays % alongside status

## Install notes

Still ad-hoc signed. Right-click then Open on first launch to bypass Gatekeeper. Existing installs auto-update via Sparkle.
