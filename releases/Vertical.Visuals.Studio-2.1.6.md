# 2.1.6

## Fixes

- Fixes new **Brunato — Titles & Description** runs missing from the Parent Episode selector when generating Shorts captions.
- The Shorts workflow now groups episode context by the underlying analysis format, so metadata-only Brunato runs and full Brunato runs can both provide the complete podcast context.
- Metadata-only entries are labeled **Titles run** in the menu so teammates can distinguish them from older full-pipeline runs.
- King’s Show and other analysis formats remain separate and cannot be selected accidentally.

## What to do after updating

Open **New Run → Brunato Talks**, enable **Shorts Captions**, and select the newest EP16 entry marked **Titles run**. Add the clips exported from Opus and generate captions normally.

## Install notes

Existing installs auto-update via Sparkle. You can force the update from **Settings → About → Check for updates**.
