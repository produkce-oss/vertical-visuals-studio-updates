# 2.3.0

## What's new

- Rebuilt Tournament Highlights thumbnails with three polished compositions: Split Impact, Center Stage, and Prize First.
- Added Designer Background uploads for finished festival artwork. VVS keeps the artwork exact and applies only the blur you choose.
- Added a dedicated background blur control and an obvious Change Background action.
- Improved title and prize hierarchy while keeping King's Resort and festival logos as exact overlays.
- Kept AI-generated backgrounds as an optional separate workflow with festival-aware color direction.
- Final thumbnails export at 1920x1080 and stay below YouTube's 2 MB upload limit.

## Install notes

Existing installs update automatically through Sparkle. To install immediately, open Settings → About → Check for Updates.
