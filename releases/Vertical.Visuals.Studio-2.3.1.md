# 2.3.1

## Fixed

- Prevents Gemini from receiving a compressed video while that file is still being written.
- YouTube upload timeouts no longer incorrectly stop the parallel compression and analysis workflow.
- Interrupted or incomplete analysis copies are automatically rejected and rebuilt safely.
- The recovery screen now recommends re-running Upload + Compress instead of downloading the original video again.
- Runs can finish with clear manual-upload guidance when titles and descriptions are ready but the YouTube draft upload failed.

## Install notes

Existing installs update automatically through Sparkle. If installing the full app manually, right-click the app and choose Open on first launch.
