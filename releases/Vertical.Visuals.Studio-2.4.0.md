# 2.4.0

## New

- Added **King's Show — Titles & Description**, a faster workflow for teammates who only need YouTube metadata.
- Choose a finished local video and VVS compresses it for Gemini, creates King's Show title options, the usual description, and tags, then opens the familiar review-and-copy screen.
- This workflow does not upload the video to YouTube. The original file stays on the Mac and YouTube publishing remains manual.

## Reliability

- Metadata-only King’s Show and Brunato runs now use the smaller 600 MB Gemini analysis copy.
- Completed King’s Show titles runs can be selected as the parent context for later King’s Show Shorts captions.
- Improved mirror validation so macOS `.DS_Store` files cannot create a false release failure.

## How to use

Open King’s Resort, start a new run, choose **King's Show — Titles & Description**, select the finished local video, fill in the episode and guest, then click **Analyze Video**.

## Install notes

Existing installs update through VVS via **Settings → About → Check for updates**.
